A playful browser drawing app that balances step-by-step lessons, open-ended creativity, and a toolset young users can understand without instruction.

UI/UXresponsive designCanvas APImicro-interactions

Live site → GitHub →

USER GOAL
Start drawing quickly, follow a lesson when needed, and see the finished sketch come alive.
FLOW
Choose guided or free draw, use a focused toolset, complete the drawing, then trigger animation feedback.
CONSTRAINT
Many drawing controls had to remain readable and reachable on smaller screens.
DECISION
Reshape the tool rail into a compact two-column system instead of forcing horizontal scrolling.

How I approach product design

working method

Make the task clear before making the screen polished.

My engineering background helps me design within real constraints, communicate implementation details, and move between visual decisions and working prototypes.

01 · FRAME

Define the task

Name the user, goal, context, constraints, and success condition before choosing an interface pattern.

02 · STRUCTURE

Map the flow

Organize content and navigation, sketch alternatives, and reuse established components before inventing new ones.

03 · PROTOTYPE

Make it testable

Define responsive layouts and interactions in Figma or code, including key states and technical constraints.

04 · VALIDATE

Review and revise

Check heuristics, accessibility, and breakpoints, gather feedback when users are available, and document the revision.

AI in the workflow: I use AI to accelerate research, alternatives, and debugging, then verify decisions against user goals, accessibility, and technical constraints.
